MaintenanceSimEnv: when should an engine be pulled from service?

A fleet of real run-to-failure engines (NASA C-MAPSS, simulated engines with recorded sensor histories). Each prediction comes from a model that never saw that engine. Pull early and you waste life. Run to failure and you pay the failure cost. Everything below updates live when you change a control.

Failure cost is an assumption (default 150 cycles of life). Score = 1 − cost / failure cost; the hindsight optimum pulls one cycle before failure. Fan speed and vibration in the 3D views are illustrations; the sensor traces, predictions and lives are real data.
