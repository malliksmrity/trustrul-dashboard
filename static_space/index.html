MaintenanceSimEnv: when should an engine be pulled from service?

Replay one of 100 real run-to-failure engines (NASA C-MAPSS, simulated engines with recorded sensor histories). Each prediction comes from a model that never saw that engine. Pull early and you waste life. Run to failure and you pay the failure cost.

The failure cost is an assumption (default 150 cycles of life). Score = 1 − cost / failure cost; the hindsight optimum pulls one cycle before failure.

The aircraft

Each engine on the aircraft is a different real engine (the first one is the engine chosen above, the others follow it). They age together. An engine spins faster as its predicted life shrinks, stops when it fails, and glows green with a ring when it has been pulled.




One engine up close

3D turbofan: drag to turn, scroll to zoom. The hot section glows from green to red as the predicted remaining life falls (the true value stays hidden). A pulled engine is shown green with a ring; an engine that reached failure flashes red.
