Predictive maintenance · aircraft engines · uncertainty

A model that estimates engine life and says how unsure it is, but its margin of error is a bit too narrow

On 100 test engines the typical error was about 13 flight cycles. Each estimate came with a 90 percent range. In practice the true value fell inside that range 82 times out of 100.

Data: NASA turbofan simulation (C-MAPSS FD001). Simulated engines. Master’s coursework (module M507), extended afterwards.

What the numbers show

A fix for the narrow range

A standard method called split conformal prediction sets the width of the range from errors on engines held back for calibration. Applied to the gradient-boosting baseline, the “90 percent” range covers of the test engines, with a width of plus or minus cycles. The same step for the GRU needs it to be retrained first, which is a planned next step. SHAP values (an explanation method) put sensors 11, 9 and 4 first for the baseline. Each prediction run is logged with MLflow. A model card lists the limits.

Look up one engine

How it works

  1. The model reads the last 30 cycles of 14 sensor channels for an engine.
  2. It predicts the cycles left. Dropout stays switched on and the prediction is repeated 50 times, which gives a spread (a range) instead of one number.
  3. If the range is in the widest quarter, the engine is flagged for a person to look at.

Limits

  • True remaining life is capped at 125 cycles, in training and in the scoring. The real values of long-life engines are higher.
  • The 90 percent range is not calibrated: 82 percent coverage on only 100 engines (so roughly 75 to 89 percent plausible). The README of the first version already called it uncalibrated; this page puts a number on it.
  • One operating condition, one fault type, simulated data. Not for real maintenance decisions.
  • The model was not retrained for this page. All numbers are read from the saved predictions in the repository.
